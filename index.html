 Le principe


      

        

          I
          
Rien ne sort de ta machine

          
Il n'y a pas de serveur. Le modèle est téléchargé une fois puis calcule en local. Coupe ta connexion après le chargement : ça fonctionne toujours.

        

        

          II
          
Ni compte, ni quota

          
Aucune inscription, aucune limite de durée ni de nombre de fichiers. Un podcast de deux heures passe aussi bien qu'un mémo de trente secondes.

        

        

          III
          
Whisper, en libre accès

          
Le moteur est le modèle de reconnaissance vocale publié par OpenAI, exécuté ici par transformers.js directement dans le navigateur.
